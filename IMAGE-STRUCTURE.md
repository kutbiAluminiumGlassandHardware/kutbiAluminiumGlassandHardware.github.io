# Kutbi Aluminium Glass & Hardware — Image Structure

All website images are stored in:

`assets/images/`

All HTML pages use page-relative paths to this canonical folder, so service and area pages do not depend on their own nested image folders.

When adding a new image:
1. Put it in `assets/images/`.
2. Use a lowercase filename with hyphens.
3. Update the relevant page to point to `assets/images/filename.ext`.
