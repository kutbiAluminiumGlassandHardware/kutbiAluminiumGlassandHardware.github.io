Common sliding window repairs

BTM Layout properties use many aluminium sliding windows and doors. With regular use, rollers can wear, handles loosen, locks stop engaging and rubber beading deteriorates. Kutbi checks the existing system and focuses on the component that needs attention.

  • Aluminium sliding window repair
  • Window roller replacement
  • Window wheel replacement
  • Aluminium window lock replacement
  • Window handle replacement
  • Rubber beading replacement
  • Sliding track and alignment checks
  • Aluminium sliding door hardware repair

Repair before replacement

If the aluminium frame is structurally usable, replacing worn hardware may be more practical than replacing the complete window. We assess the condition of the frame, glass, rollers, track and locking mechanism before suggesting a solution.
