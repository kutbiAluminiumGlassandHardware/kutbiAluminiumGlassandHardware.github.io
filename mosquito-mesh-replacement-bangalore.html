When to Replace Mosquito Mesh

  • Mesh is torn or has multiple holes
  • Mesh is old, brittle or badly worn
  • Mesh has become loose and cannot be suitably secured
  • Velcro fixing has worn out
  • Magnetic mesh is damaged
  • Existing mesh no longer provides proper coverage
  • Window or door mosquito net needs a fresh mesh
  • Existing mesh system needs compatible replacement
