# Kutbi Bangalore Local SEO Website — Upgrade

This package adds:
- 25 distinct Bangalore area pages
- 25 service/area combination pages
- LocalBusiness + Service/area JSON-LD on new pages
- image-sitemap.xml
- refreshed sitemap.xml and robots.txt
- Areas hub and Services hub
- stronger internal linking

## Important SEO rule
Do not mass-create hundreds of pages with the same copy and only the location changed. Keep each local page useful, specific and supported by real service coverage.

## Deploy
Replace/upload the contents of this package to the GitHub Pages repository:
`kutbialuminiumglassandhardware.github.io`

Then verify:
1. GitHub Pages is serving the new files.
2. Open `/sitemap.xml` and `/image-sitemap.xml`.
3. In Google Search Console, submit the sitemap.
4. Inspect the homepage and a few area pages for indexing.
5. Add real project photos to the relevant service/area pages over time.
